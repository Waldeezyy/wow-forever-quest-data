- Imported Polestar guide content retains its **GPL-3.0-only** declaration and upstream attribution. See the source manifest and `licenses/` notices included with a dataset.
- Polestar's compiler exception permits certain author-created packs under chosen terms. It is not a blanket relicensing grant for copied Polestar built-in guide text or engine code.
- Upstream reference data may have distinct rights/provenance. The Polestar data notices and QuestieDB's qualified historical-license statement should be reviewed before redistribution or incorporation into another product.
- No paid Zygor/RestedXP guide content, authentication material, game binaries, navigation meshes or recorded gameplay are included.
- No blanket license has been selected for newly written repository tooling. An explicit tooling license can be agreed before it is incorporated into the developer's project. This does not replace or change upstream content licenses.
